# Privacy

Effective date: 2026-09-03

ELISA Pilot Dilution Planner performs its calculations in the browser. The current release candidate has no account system, analytics, advertising, backend, database, cookies, or network request made by the application code.

Concentration values, volume settings, and calculated plans are held only in the open page and are not persisted by the application. The tool may store one language preference (`English` or `Traditional Chinese`) in the browser's local storage. Clearing site data removes that preference.

When the tool is later hosted, the hosting provider may process ordinary request metadata such as IP address, browser information, requested URL, and request time to deliver and protect the site. This document must be updated with the actual hosting details before public deployment.

No payment or support service is connected in this release candidate. A future support link will lead to a separate service with its own privacy terms.
